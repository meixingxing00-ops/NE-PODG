# NE-PODG 论文结构设计

叙述与证据取舍按仓库根目录的 `论文叙述约定.md`；方法以 `方法设计.md` 为准，算例以 `cases/nc/实例化设计.md` 为准。当前以方腔自然对流（nc）为唯一算例，增加算例时只改 2.1、2.7 与第 3 章各节内部的分节。初稿用中文（ctex），定稿译为英文。写作顺序：先第 2、3 章，再组织引言。

## 主线

场值监督训练的网络为 SA-PODG 提供互补空间；该空间捕获基础空间未表示的解余量，经 Galerkin 闭合转化为速度场精度的提升，温度与 Nu 的预测随之改善。

- 2.1–2.3：方腔模型、离散求解形式与 SA-PODG 基础空间。
- 2.4–2.6：NE-PODG 的构造及其误差关系。
- 2.7：数值验证、数据设计与复现设置。
- 3.1–3.2：整体精度与传热量预测。
- 3.3–3.4：增广收益的来源与增广维数。
- 4：结论；方法的局限集中在最后一段。

## 骨架

**1. Introduction（引言）**
研究背景、参数化降阶空间的表示问题、神经互补增广的思路、本文贡献。

**2. Methodology（方法）**

| 小节 | 内容 |
|---|---|
| 2.1 Problem description（问题描述） | 二维方腔、Boussinesq 方程、边界条件、$Ra$ 与 $Pr$、平均与局部 Nu 的定义 |
| 2.2 Full-order discretization and solution formulation（全阶离散与求解形式） | MAC 离散与流函数表示；主场 $\psi$、辅助温度场及二者的耦合；温度消元后的有效残差与雅可比 $J_{\mathrm{eff}}$；主场度量 $M$（速度 $L^2$） |
| 2.3 Sensitivity-augmented base space（灵敏度增广基础空间） | 快照 POD 空间 $V$；离散稳态灵敏度 $S$；$W=V\oplus S$ |
| 2.4 Value-supervised neural candidate fields（场值监督的神经候选场） | 网络结构、容许映射、场值监督训练；读出偏置导数关系 |
| 2.5 Complementary space construction and Galerkin closure（互补空间构造与 Galerkin 闭合） | $Z_\theta(\eta)$；$W\oplus Z_\theta$ 上的降阶方程；Fig. 2 |
| 2.6 Approximation and error characterization（逼近与误差刻画） | $e$、$e_{\mathrm{proj}}$、$\Gamma$、$\chi$ 的定义；增广空间上最佳逼近误差与求解误差的两个关系式 |
| 2.7 Numerical implementation and verification（数值实现与验证） | 高保真解的基准对照（Table 1）；训练池、快照预算、测试工况；网络与闭合设置（Table 2）；计算环境 |

**3. Results and discussion（结果与讨论）**

| 小节 | 内容 |
|---|---|
| 3.1 Accuracy across the parameter domain and snapshot budgets（参数域与快照预算上的精度） | POD–Galerkin、SA-PODG、NE-PODG；内插与外推；四档预算的总体趋势（Fig. 3、Table 3）；种子稳健性 |
| 3.2 Flow-field reconstruction and heat-transfer predictions（流场重构与传热量预测） | 代表工况的流函数、速度场、温度场及误差分布；局部与平均 Nu；温度误差与速度误差同步变化（Fig. 4） |
| 3.3 Contribution and accuracy mechanism of neural enrichment（神经增广的贡献与精度机制） | 训练与未训练网络对照 → $\Gamma$ → $\chi_B/\chi_W$ → 精度提升的来源（Fig. 5） |
| 3.4 Influence of enrichment dimension（增广维数的影响） | 固定网络截断到 8、16、32、64、128 维时的精度变化；增广维数由截断直接选取，不需重训（以较小输出维数重训的结果作为印证，写作时讨论）（Fig. 6） |

**4. Conclusions（结论）**
方法、精度提升、增广机制、维数规律。最后一段写局限：验证范围限于单一算例；在线闭合中温度场在全网格上求解，在线耗时与高保真求解相当，温度场降阶留作后续工作。
