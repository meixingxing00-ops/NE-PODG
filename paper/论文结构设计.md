# NE-PODG 论文结构设计

叙述与证据取舍按仓库根目录的 `论文叙述约定.md`；方法以 `方法设计.md` 为准，各算例以 `cases/<算例>/实例化设计.md` 为准。初稿用中文（ctex），定稿译为英文。题目拟用 *Neural-enriched POD–Galerkin model reduction for parametrized steady heat-transfer problems*。

## 主线

方法构造 → SA 互补增广 → 求解精度提升 → 余量捕获机制 → 跨问题验证。第 2 章把 NE-PODG 写成通用的空间增广方法；第 3 章用不同类型的稳态传热问题说明增广改善什么、改善多少、收益从何而来。

- 2.1–2.5：通用的问题表述、投影降阶与基础空间、NE-PODG 的构造与误差关系。
- 2.6：算例与数值设置。
- 3.1–3.2：跨算例的精度、场与传热量。
- 3.3：增广机制。
- 3.4：增广维数与快照预算。
- 4：结论；方法的局限集中在最后一段。

## 算例与详略

| 算例 | 角色 | 正文内容 | 默认预算 |
|---|---|---|---|
| 方腔自然对流（nc） | 主算例：非线性流热耦合，流函数为主场、温度为辅助场 | 精度、场与剖面、网络训练与直接输出、机制全流程、维数、预算、种子 | $N_{12}$ |
| Couette–Graetz（graetz） | 第二算例：线性非对称对流扩散，温度为主场、无辅助场，含几何参数 | 精度、受热壁附近温度与局部 Nu（Fig. 6）、网络直接输出一两句、$\Gamma$ 与 $\chi_B/\chi_W$ | $N_4$（训练区四角） |
| 通道共轭传热（conjugate） | 流固界面与导热率跳变，温度为主场，线性 | 精度、界面附近温度与界面热流（Fig. 6）、$\Gamma$ 与 $\chi_B/\chi_W$ | $N_4$ |
| 顶盖驱动混合对流（mixed） | 剪切与浮力共同驱动的非线性流热耦合，(Re, Ri) | 汇总图表一行、$\Gamma$ 与 $\chi_B/\chi_W$；场图放附录 C | $N_4$ |
| 多孔方腔自然对流（porous） | Darcy–Brinkman 阻力下的非线性流热耦合，(Ra*, Da) | 同 mixed | $N_4$ |
| 后台阶流动传热（bfs） | 开口分离流动，含几何参数 ER，(Re, ER) | 精度、回流结构与受热壁 Nu（Fig. 6）、$\Gamma$ 与 $\chi_B/\chi_W$；在跨算例讨论中作为余量捕获率较低、闭合放大大于 1 的一端 | $N_4$ |

- 纳入条件：高保真验证合格，三种方法在同一离散上完整跑通。不按增益大小取舍。
- 正文顺序：nc → graetz → conjugate → mixed → porous → bfs。
- bfs 的网络输入坐标、边界因子与提升只写最终定义（Table 1、Table 2、附录 A）。
- 快照预算：各算例按问题性质取少量覆盖训练区的参数点，不强求快照数相同。每个算例报告 $N_s$、$n_V$、$n_S$、$n_Z$。
- 跨算例比较：同一算例、同一预算下的 $e_{\mathrm{NE}}/e_{\mathrm{SA}}$，以及两种方法各自的绝对误差。主统计用拉丁超立方内插测试与外推测试；graetz 训练池中快照以外的 31 点作为附加检验，放附录 C。
- 机制：训练与未训练网络的对照、维数、预算与种子只在 nc 上做；每个算例都报告 $(e_{\mathrm{SA}},e_{\mathrm{NE}})$、$\Gamma$ 与 $\chi_B/\chi_W$。跨算例结论为：精度收益主要来自互补空间对余量的捕获（$\Gamma$），实际求解收益由 $\Gamma$ 与各算例的 $\chi_B/\chi_W$ 共同决定。逐工况分解 $\ln(e_W/e_B)=-\tfrac12\ln(1-\Gamma)-\ln(\chi_B/\chi_W)$，按算例给出最佳逼近项大于闭合项的工况比例（不报跨算例汇总数），一句结果陈述，不另设图。
- 局部特征量（如 bfs 的 $x_r$）与主场误差不同步的统计如实给出数值，不另加解释。
- 文献基准：graetz 取 Quarteroni, Rozza & Manzoni (2011) §8.1 的问题设置，原文为有限元离散，只对照物理输出量 $T_{\mathrm{av}}$，不把原文的降阶精度与耗时当作对照数据。

## 骨架

**1. Introduction（引言）**
参数化稳态传热问题的多查询需求；降阶建模与有限快照空间的表示问题；灵敏度增广；神经网络在降阶中的两类用法；神经互补增广的思路。三条贡献，依次为方法、解释与适用范围：方法构造（网络参与试探空间构造，不直接预测系数或解：场值监督的神经候选空间、SA 互补增广、Galerkin 闭合）；误差机制（余量捕获率与闭合放大系数的误差关系，辨识两者在不同问题中的作用；训练网络的对照）；跨问题验证（稀疏快照下的线性对流扩散、共轭传热、非线性流热耦合（自然对流、混合对流、多孔介质）与开口分离流动，主场与传热输出量）。

**2. Methodology（方法）**

| 小节 | 内容 |
|---|---|
| 2.1 Problem formulation（问题描述） | 参数化二维稳态对流传热问题的共同形式：流动与能量守恒、参数可为物性、流动或几何参数；几何参数映射到固定参考域，网格在参考域上固定；传热输出量为解的泛函。各算例的方程与边界条件见 2.6 与附录 A |
| 2.2 Projection-based reduced-order model and base space（投影降阶与基础空间） | 主场 $\mathbf q$ 取容许坐标（非齐次边界值由与参数无关的提升承担）、辅助场 $\mathbf z$（可为空，此时 $r_{\mathrm{eff}}=F$）；有效残差与 $J_{\mathrm{eff}}$、度量 $M$；投影降阶的通用 Galerkin 方程（试探基 $X$），由此说明快照、参考解与降阶求解基于同一离散；有效残差对 $\mathbf q$ 线性时直接求解，非线性时用 LM；依次取 $X=V$（POD–Galerkin）、$X=W=[V,S]$（SA-PODG，引 Hay 等，每个训练点都算灵敏度） |
| 2.3 Value-supervised neural candidate fields（场值监督的神经候选场） | 候选场（经通用容许映射 $\mathcal A_h$）、线性读出、场值监督损失；读出偏置导数关系；训练过程见附录 B.1 |
| 2.4 Complementary space construction and Galerkin closure（互补空间构造与 Galerkin 闭合） | 神经候选场的正交互补构造 $Z_\theta(\eta)$；NE-PODG 在 2.2 的 Galerkin 方程中取 $X=\Psi_\theta=[W,Z_\theta]$；三种方法的试探空间依次为 $V\subset W\subset\Psi_\theta$；Fig. 2 |
| 2.5 Approximation and error characterization（逼近与误差刻画） | $e$、$e_{\mathrm{proj}}$、$\Gamma$、$\chi$ 的定义；增广空间上最佳逼近误差与求解误差的两个关系式 |
| 2.6 Benchmark problems and numerical settings（算例与数值设置） | 各算例一段物理描述（参数、边界条件、传热输出量；方程在附录 A）；Fig. 1；算例总表 Table 1（物理问题、参数与训练区/外推区、主场与辅助场、度量与容许映射、高保真离散与自由度、默认预算与 $n_V$、$n_S$、测试工况数、传热输出量）；高保真解（同一套自编离散，各算例的验证结论各一句，细节见附录 A）；误差度量（主场误差 $e$ 按容许增量 $\Vert\mathbf q^\star\Vert_M$ 归一，流函数主场即速度增量的 $L^2$；各算例的传热量误差；内插与外推分别统计中位数与最大值）；计算设置 Table 2（网络、训练、空间构造、闭合，算例间不同的项分列） |

**3. Results and discussion（结果与讨论）**

| 小节 | 内容 |
|---|---|
| 3.1 Accuracy across benchmark problems（跨算例的精度） | 开头一段说明各算例覆盖的数学与物理特征，不另设表；主场误差分布与逐工况增益由 Fig. 3 承担；传热量误差的中位数 / 最大值由 Table 3 承担，主场误差不在表中重复 |
| 3.2 Flow and heat-transfer predictions（流场与传热预测） | 围绕三个共同问题：主场的空间结构是否恢复、高梯度区的误差、传热量是否同步改善。nc 的场误差（Fig. 4）与中线速度、局部 Nu（Fig. 5）；Fig. 6 按物理特征取 graetz、conjugate、bfs 三个算例，每个一组面板：参考场、SA-PODG 与 NE-PODG 的误差，加局部 Nu、界面热流或受热壁 Nu；mixed、porous 的场图放附录 C。正文讨论共同表现与有意义的差异，不逐个算例叙述 |
| 3.3 Mechanism of neural enrichment（神经增广的机制） | nc：训练收敛（Fig. 7a）→ 训练快照拟合好 → 测试点直接输出差 → NE-PODG 仍准（Fig. 7b、Table 4）；graetz 的网络直接输出用一两句补充，不另设图；收益归于神经候选空间、SA 基础空间与 Galerkin 闭合组成的方法，不表述为对网络预测值的修正。训练与未训练网络对照（Fig. 8a，nc）→ 各算例的 $\Gamma$（Fig. 8b）→ 各算例的 $\chi_B/\chi_W$（Fig. 8c）；逐工况分解的结果一句陈述 |
| 3.4 Enrichment dimension and snapshot budget（增广维数与快照预算） | nc：单次训练的候选空间经方向截断适配不同增广维数，与较小输出维数重训对照；四档预算下三种方法的误差，快照越少 NE-PODG 优势越大；种子稳健性（$N_{12}$、$N_{50}$）（Fig. 9、Table 5） |

**4. Conclusions（结论）**
方法、跨算例的精度结果、机制结论、维数与预算规律。最后一段写局限：降阶只施加于主场，辅助场仍在全网格上求解；NE-PODG 的单次查询耗时高于 SA-PODG；耗时以附录 C 的统一口径为准。
