# 后台阶流动传热：实验记录

## 2026-11-11 网格研究与出口长度（初步，参数域未定）

`fom/grid_study.py`，PINNGPU，openmac cuDSS 后端。几何与边界取 `solvers/openmac/benchmarks.bfs`：入口高 $h=1$，入口段 $L_{\rm in}=4h$、抛物线入口（平均速度 1），台阶在 $x=0$，出口距台阶 $L_{\rm out}=40h$；台阶下游下壁定温 $T=1$，入口 $T=0$，其余壁绝热；$Re=2U_bh/\nu$，$Pr=0.71$。$n$ 为每个入口高度的单元数，主场维数 $n=24$、32、48、64 时分别为 23664、42304、95712、170624。每个 ER 从 $Re=100$ 起逐档延拓到 800，全部收敛。长度以 $S=(ER-1)h$ 计，局部 Nu 以 $S$ 为长度、入口温度为参考。结果 `results/fom/grid.csv`（n=24–48）、`grid64.csv`、`outlet.csv`。

$n=64$ 时 Newton 步长降到 $2\times10^{-14}$，残差停在约 $2\times10^{-10}$（舍入下限），故 $n=64$ 取收敛判据 $10^{-9}$，其余网格为 $10^{-10}$。

各输出（$x_r$、上壁分离与再附着、$Nu_{\max}$、受热壁平均 Nu、$x/S=1,2,5,10,20$ 处局部 Nu）相对 $n=64$ 的最大相对差：

| ER | Re | $n=32$ | $n=48$ |
|---|---:|---:|---:|
| 1.5 | 100–400 | ≤ 0.34% | ≤ 0.09% |
| 1.5 | 600 | 0.45% | 0.12% |
| 1.5 | 800 | 0.59% | 0.15% |
| 2 | 100–300 | ≤ 0.97% | ≤ 0.25% |
| 2 | 400 | 1.25%（$Nu_{\max}$） | 0.32% |
| 2 | 600 | 0.71% | 0.18% |
| 2 | 800 | 6.64%（$x=10S$ 处 Nu） | 1.62%（同左） |

- $ER=2$、$Re=400$ 起上壁出现分离区，长度随 Re 增大（$Re=600$ 为 $8.3S$–$15.9S$）。
- $ER=2$、$Re=800$ 时 $x_r/S$ 随网格加密为 11.36、11.58、11.72、11.77，Gartling (1990) 为 12.20（入口在台阶处，出口条件不同）；上壁 9.28 / 20.54，文献 9.70 / 20.96。
- 出口长度：$n=32$ 上把出口从 $40h$ 延到 $60h$（原网格节点不变，只在出口后加单元），Re = 200–800 的全部输出相对变化不超过 $2\times10^{-10}$，出口无回流。
- 计算量：$n=64$ 每个工况 8–15 s（含延拓与输出），$n=48$ 约 5 s。

初步判断：$Re\le600$ 时 $n=48$ 的输出相对 $n=64$ 不超过 0.32%，$n=32$ 不超过 1.25%；$Re=800$、$ER=2$ 的下游局部 Nu 在 $n=48$ 仍有 1.6% 的变化。
