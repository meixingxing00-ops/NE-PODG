## 2026-11-09 在线闭合优化与查询耗时

`solvers/mac/gpu.py`：$J_{TT}$ 每次迭代只分解一次，温度与灵敏度共用；灵敏度右端项列数取基方向数 $k$（原为固定 256 列）；与状态无关的 $C\Psi_B$、$AW$、$HW$、$KW$、$A_eW$ 每个基只算一次。基线全部结果文件（四档预算的 pod、sapodg、VS_v 及 N12、N50 的 VS_v1、VS_v2）在新代码上重跑。

- 结果不变：各工况 $e$、$e_T$、$e_{Nu}$ 与原结果的绝对差 ≤ 6×10⁻¹⁴，收敛与 LM 迭代数逐工况相同。相对差大于 10⁻³ 的只出现在误差本身 ≤ 2×10⁻¹¹ 的工况（舍入水平）。
- 单次 `reduced`（Ra = 10⁶ 状态，随机基）：k = 29、88、157、216 时由 21、30、33、44 ms 降到 5.1、16.7、20.8、35.0 ms。剩余耗时主要是 $k$ 列灵敏度回代（耗时约与列数成正比）与 $W^{\mathsf T}X$ 稠密乘积（float64，k = 216 时约 14 ms）。
- 单次查询耗时中位数（各档预算的范围）：SA-PODG 内插 0.087–0.12 → 0.023–0.070 s、外推 0.15–0.38 → 0.070–0.17 s；VS_v 内插 0.48–0.55 → 0.44–0.54 s、外推 0.70–1.16 → 0.67–1.06 s。
- VS_v 的网络方向与去投影（`run.py` 新增列 `time_basis`）每次查询 0.27–0.28 s，占 VS_v 查询的 25–60%。其中网络前向 0.6 ms，两次 32512×128 的 float64 SVD（候选方向正交化与去 $W$ 分量）各约 115 ms（初步，单个工况计时）。

## 2026-11-09 去投影的 SVD 与主角正弦谱

`nepodg/space.py` 的 `_orth` 改在 CPU 上做 SVD：白化候选矩阵 32512×128（float64）的 SVD 在 CPU 上 40 ms，GPU 上 114 ms。`complement` 单次由约 265 ms 降到 140–160 ms。32 个结果文件重跑。

- 耗时：`time_basis` 由 0.27–0.28 s 降到 0.14–0.17 s；VS_v 单次查询中位数内插 0.27–0.38 s、外推 0.45–0.77 s。
- 闭合误差不变：$e$ 的中位数之比 1.000000–1.000003，逐工况相对差 ≤ 3.4×10⁻⁴（出现在 $e\sim3\times10^{-11}$ 的工况）；$n_Z$ 逐工况相同。
- 白化后 $\Phi$ 的条件数：$\sigma_{\min}/\sigma_1$ 训练网络为 5×10⁻⁸–2×10⁻⁵（N12、N50，6 个参数点），未训练网络 r1、r2 为 3×10⁻⁷–4×10⁻⁷。网络在 float32 下求值，$\sigma/\sigma_1\lesssim10^{-7}$ 的方向处在 float32 舍入水平。$\delta_E=10^{-8}$ 的判秩要分辨到这一量级，需要正交分解；Gram 矩阵类方法把条件数平方，不能用。
- 主角正弦的简并：$k_W<m$ 时 $\operatorname{span}\Phi$ 与 $W$ 之间至多 $k_W$ 个主角小于 90°，其余 $m-k_W$ 个 $s$ 恰为 1（Ra = 10⁶、Pr = 0.1 处 N12 为 99/128，N50 为 40/128）。$s=1$ 的方向之间没有次序，`z<r>` 按 $s$ 取前 $r$ 个时，$r\le m-k_W$ 的结果由 SVD 实现任意决定：GPU 与 CPU 两种 SVD 的前 16、32 个方向张成的子空间相距 0.4–0.9。截断维数的实验需要另定方向的排序。
- $e_{\mathrm{proj}}$ 在 $e\lesssim10^{-9}$ 时不可靠：$e_{\mathrm{proj}}>e$ 的工况 N30 VS_v 内插 45/100、N50 VS_v（三个种子）内插 47–49/100、SA-PODG 10–25/100，这些工况全部 $e\le1.1\times10^{-9}$，$e_{\mathrm{proj}}/e$ 最大 140。原因是闭合用的状态基 $B$ 与计算 $e_{\mathrm{proj}}$ 用的白化基 $B_w$ 不一致：whiten($B$) 与 $B_w$ 逐列相差 5×10⁻⁷–7×10⁻⁷，来自保留的 $\sigma/\sigma_1\sim10^{-8}$ 的 POD 模态与 $\Phi$ 方向（状态基 $XQ\sigma^{-1}$ 放大舍入）。$e=e_{\mathrm{proj}}+e_{\mathrm{real}}$ 的分解只在 $e$ 明显高于这一水平的工况上可用。

## 2026-11-09 截断排序与 e_proj 的计算

- `z<r>` 改为候选空间只取 $\Phi(\eta)$ 的前 $r$ 个奇异方向（$M$ 范数下按奇异值从大到小，`space.complement(..., r)`），再去 $W$ 分量，$n_Z\le r$。N50、4 个工况上，GPU 与 CPU 两种 SVD 给出的前 8、16、32、64 个方向的子空间相距 ≤ 6×10⁻¹³，截断结果与 SVD 实现无关；所取 $r=16$、64 个方向全部保留（$n_Z=r$）。这一次序依赖 $\Phi$ 各列的尺度。
- $e_{\mathrm{proj}}$ 改按闭合所用状态基张成的空间计算（`metrics.basis`：whiten($B$) 的 QR）。N50 VS_v 的 I001、I005：$e_{\mathrm{proj}}$ 由 3.9×10⁻¹⁰、1.7×10⁻⁹ 降到 2.4×10⁻¹¹、2.0×10⁻¹¹（$e$ = 2.9×10⁻¹¹、2.3×10⁻¹¹）；$e\gtrsim10^{-9}$ 的工况不变。
- 32 个结果文件重跑：全部工况 $e_{\mathrm{proj}}\le e$，$e_{\mathrm{real}}$ 不再出现 0；$e$、$e_T$ 与上一次重跑的绝对差 ≤ 6×10⁻¹⁵（GPU 运算的逐次舍入差异），收敛与 $n_Z$ 逐工况相同。

- 有效维数：未训练网络白化后的 $\Phi$ 快速衰减，128 个方向中 74 个 $\sigma/\sigma_1<10^{-6}$，处在 float32 求值的舍入水平（与 float64 求值的方向偏离到 0.56–1.0）。可分辨的方向约 12（$>10^{-4}$）到 54（$>10^{-6}$）个。训练网络约 90 个方向 $>10^{-4}$，116–125 个 $>10^{-6}$。上节"未训练网络 128 维的精度相当于训练网络 16–32 维"，与未训练网络可分辨方向数同一量级。同名义维数的对照混入了有效维数的差别，增益是否超出有效维数的作用尚未分离。
- 参数依赖：训练网络的 $\operatorname{span}\Phi(\eta)$ 随 $\eta$ 部分变化。任两点之间约一半方向基本相同（正弦 <0.1），30–50 个方向相差大（正弦 >0.5）。15 个点的并约 120 维（σ² > 0.5）、约 190 维（σ² > 0.1），远小于互不相关的 1920 维。$Ra=10$ 与 $Ra=10^4$、$10^6$ 的差别相近（$U$ 的正弦中位数：种子 1234 为 0.07–0.12，种子 1 为 0.09–0.25），不随参数距离明显增大。结合上节固定参数的结果：变化的那部分方向对精度没有一致的作用。
- 未训练网络：只有前约 20 个方向在各参数点之间一致，其余方向在任两点之间几乎正交（正弦中位数 0.96–0.97），这与这些方向处在舍入水平一致。

推断（初步）：训练改变了 $\Phi$ 的奇异值谱，把可分辨的方向数从几十提高到百余个；这一项至少解释了训练网络与未训练网络的部分差距。
