- VS_v 在全部预算与区段低于 SA-PODG：速度中位数 2.1–9.3 倍，温度 2.3–25 倍，平均 Nu 3.6–300 倍。优势随预算增加而减小（N12 3.5–9.3 倍，N50 2.1–3.5 倍）。
- 最大速度误差（内插 / 外推，%）：VS_v 为 N12 0.442 / 2.14、N20 0.149 / 2.20、N30 0.289 / 1.28、N50 0.0149 / 1.06；SA-PODG 为 1.96 / 10.4、0.511 / 7.60、0.704 / 3.27、0.0349 / 1.74。
- 维数：$n_V$ = 11、16、24、35，$n_S$ = 18、26、38、53，$n_Z$ 中位数 128。
- 单次查询耗时中位数（网络方向、去投影与闭合）：VS_v 内插 0.48–0.55 s、外推 0.70–1.16 s；SA-PODG 内插 0.09–0.12 s、外推 0.15–0.38 s。
- 种子（N12、N50 另以种子 1、2 训练，`train.py B 1` 等，结果 `VS_v1_*`、`VS_v2_*`）：三个种子的速度中位数之比（最大 / 最小）为 1.10–1.41；取三个种子中最差者，仍比 SA-PODG 低 2.0–6.6 倍。最大速度误差 N12 为 0.442–0.490 / 1.57–2.17%，N50 为 0.0149–0.0176 / 0.959–1.06%。
