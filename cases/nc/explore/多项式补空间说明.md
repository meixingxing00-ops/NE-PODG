# 多项式补空间：构造、结果与机理（方腔自然对流，初步）

本研究中多项式补空间是对照组，用于检验神经增广的增益是否来自通用光滑函数；它不是我们提出的方法。

## 1. 问题与基础空间

- 算例：方腔自然对流，参数 μ = (Ra, Pr)，训练区 Ra ∈ [10, 3.16×10⁵]、Pr ∈ [0.1, 10]，外推到 Ra = 4.22×10⁵、5.62×10⁵、1.00×10⁶。主场为流函数 ψ，度量为速度 L² 范数，闭合为 Galerkin 投影加 LM 求解。
- V：训练快照的完整 POD。S：各训练点处 ψ 对 log10 Ra、log10 Pr 的稳态灵敏度。V⊕S 即 SA-PODG 空间（Hay, Borggaard & Pelletier 2009 的扩展基）。

## 2. 构造

- 坐标映到 [−1, 1]²，取 Legendre 多项式乘积 P_a(x)P_b(y)，a + b ≤ d。
- 每个函数乘边界因子 𝓑 = 256x²(1−x)²y²(1−y)²（x, y ∈ [0, 1]），使其满足 ψ = 0、∂ψ/∂n = 0。
- 维数：d = 6、10、14、20 分别为 28、66、120、231。
- 用法与网络方向相同：去掉 V⊕S 分量后正交化（主角正弦 > 10⁻⁶ 保留），加入降阶空间后闭合。多项式与数据、参数都无关。

## 3. 结果（外推 Ra = 1.00×10⁶，9 个工况中位数，%）

N12（12 个训练快照）：

| 空间 | 维数 | 最佳逼近误差 | 闭合误差 |
|---|---|---|---|
| V⊕S（SA-PODG） | 29 | 2.05 | 2.72 |
| V⊕S + 网络方向 | 157 | 0.320 | 0.413 |
| V⊕S + 多项式 d = 14 | 149 | 0.143 | 0.214 |

- Ra > 10³ 的 82 个测试工况上，V⊕S + 多项式的闭合误差全部低于 V⊕S + 网络方向与 SA-PODG，全部收敛。
- 四档快照预算（12、20、30、50）、两种基础空间（V 与 V⊕S）上，同维数下多项式的最佳逼近误差都低于网络方向。

## 4. 机理

记 r(μ) = u(μ) − Π_{V⊕S} u(μ)（M 范数下的正交余量），P_d 为上述多项式空间。因 r ⊥ V⊕S，对任意 p ∈ P_d，r − (I − Π_{V⊕S})p = (I − Π_{V⊕S})(r − p)，故

  e_proj(V⊕S⊕P_d) ≤ min_{p ∈ P_d} ‖r − p‖ = e_proj(V⊕S) · ε_d(r)，

ε_d(r) 为余量 r 的 d 次多项式相对逼近误差。

- e_proj(V⊕S) 是参数方向的插值误差（快照为 Lagrange 型、灵敏度为 Hermite 型），快照越稀疏、外推越远越大。
- ε_d(r) 只取决于 r 作为空间函数的光滑性，与快照分布无关；稳态解光滑，Legendre 逼近谱收敛，主要受边界层厚度 δ ~ Ra^(−1/4) 限制。
- 两项相乘，因此快照越稀疏，多项式带来的改善越大。不等式严格成立；"本算例的增益主要由此机制解释"是由数据走势支持的推断，上界紧度尚未直接核对。
