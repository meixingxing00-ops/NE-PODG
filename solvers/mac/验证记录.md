## 2. 恒速顶盖驱动方腔（`lid`，Re = 100 → 400 → 1000 延拓）

Re = 1000 相对 Botella & Peyret (1998) 的偏差（$\psi_{\min}$ 取角点网格值，其余为中线样条插值的极值）：

| 网格 | $\psi_{\min}$ | $u_{\min}$ | $v_{\max}$ | $v_{\min}$ |
|---|---|---|---|---|
| 64，均匀 | −4.48% | −5.72% | −5.63% | −5.21% |
| 128，均匀 | −1.20% | −1.53% | −1.50% | −1.38% |
| 256，均匀 | −0.30% | −0.39% | −0.38% | −0.35% |
| 128，s = 1.5 | −0.23% | −0.37% | −0.34% | −0.14% |
| 256，s = 1.5 | −0.056% | −0.092% | −0.084% | −0.034% |

- 均匀网格加密一倍偏差约降为 1/4，二阶收敛。
- Re = 100、400 的 $\psi_{\min}$（256，s = 1.5）为 −0.103513、−0.113955，与 Ghia 等 (1982) 的 −0.103423、−0.113909 差 0.09%、0.04%。

## 3. 侧壁差分加热自然对流（`nc`，Pr = 0.71，log10 Ra = 3 → 6，步长 0.5）

冷壁平均 Nu 相对参考值 1.1178、2.2448、4.5216、8.8252（Ra = 10³–10⁶；8.8252 为 Le Quéré (1991)，其余三个待核对出处）的偏差：

| 网格 | 10³ | 10⁴ | 10⁵ | 10⁶ |
|---|---|---|---|---|
| 64，s = 1.5 | +0.004% | +0.032% | +0.104% | +0.277% |
| 128，s = 1.5 | 0.000% | +0.008% | +0.026% | +0.064% |
| 128，s = 2.5 | −0.004% | −0.005% | −0.003% | −0.024% |
| 256，s = 2.5 | −0.002% | −0.001% | 0.000% | −0.006% |

- Ra = 10⁶：128、256、512 网格（s = 2.5）平均 Nu 为 8.82312、8.82468、8.82507，相邻差之比 4.0（二阶收敛），Richardson 外推 8.82520。
- 冷、热壁平均 Nu 一致到显示位数；二次插值壁面梯度与格式自身的壁面通量在 s = 2.5 下一致到 1e-5。
- 由收敛解的 ψ 单独求辅助场温度，与耦合求解的 T 相差 ≤ 1.9e-13（256、512 网格）。

## 4. 与 COMSOL 快照的平均 Nu 对照（`comsol`）

MAC 128 网格、s = 2.5；COMSOL 为 paper-podnn 训练池 55 个工况（log10 Ra = 1–6、间隔 0.5，Pr = 0.1、0.3、1、3、10，1/255 网格，冷热壁平均）。全部工况收敛。

- 偏差（MAC 相对 COMSOL）在 −0.087% 到 +0.032% 之间：Ra ≤ 100 时 ≤ 0.005%；Ra = 10³ 时 −0.043% 到 −0.044%（五个 Pr 相同）；Ra = 3.16×10³–3.16×10⁵ 时 −0.02% 到 −0.09%；Ra = 10⁶ 时 −0.04% 到 +0.03%。
- 偏差主要来自 COMSOL：MAC 在 128 与 256 网格上的平均 Nu 相差 ≤ 0.02%（Pr = 0.71，Ra = 10³–10⁶）；COMSOL 在 Ra = 10⁶、Pr = 0.71 的五级网格（1/128–1/512）上平均 Nu 为 8.8262、8.8349、8.8254、8.8288、8.8205，不单调，波动约 0.17%。

## 5. 线性求解器与耗时

- cuDSS（float64）与 SciPy SuperLU 在同一延拓序列上逐参数点比较全部未知量：自然对流 256 网格最大相对差 1.5e-13，顶盖 256 网格 1.1e-15，Newton 迭代次数相同。
- 每个参数点 Newton 迭代 4–7 次。单个参数点：128 网格约 0.2 s，256 网格 0.6–0.9 s，512 网格约 4.3 s（每个网格首个参数点另含一次符号分析）。256 网格的单步 Newton：组装雅可比 0.075 s，数值分解 0.063 s，回代 0.002 s。
- 辅助场温度加 128 个灵敏度方向，单次调用：128 网格 0.053 s，256 网格 0.21 s（只算温度 0.027 s，右端项 0.023 s，128 列回代 0.084 s，回代中主要是右端项与解在主机与 GPU 之间的往返）。
